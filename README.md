# 🕊️ Pigeon Core

A powerful Minecraft modding framework designed to enforce cross-mod compatibility, and provide a streamlined auto-registration system.

## Project Status

- **Status:** In Active Development (~50% completed)
- **Target Version:** Minecraft 1.20.1 (**Forge**) and others in the future
- **Java Requirement:** Java 17 - 21
- **Back-porting:** None planned.

> **Developer Prerequisite**
> Pigeon Core is designed to make professional modding *better and simpler, but not necessarily easier*. To use this framework, you must have solid **Java knowledge** and a fundamental understanding of **Minecraft Modding**.

## Key Features

* ⚡ **Auto-Registration System:** A simple yet powerful system that handles registries automatically, drastically reducing boilerplate code.
* 🔄 **Cross-Mod Compatibility:** Built from the ground up to make different mods using this, natively compatible with one another.
* 🦎 **GeckoLib 4+ Integration:** Built-in, native support for GeckoLib animations. *Note: The framework works flawlessly even without it.*
* ⚙️ **Fully Customizable:** You retain 100% full control over everything; change what you need.

### Ecosystem Support

| Category | Supported Features |
| :--- | :--- |
