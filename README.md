# 🐦 Pigeon Core

A powerful Minecraft modding framework designed to generalize core concepts, enforce cross-mod compatibility, and provide a streamlined auto-registration system.

---

## 📊 Project Status & Specs

- **Status:** In Active Development (~50% completed)
- **Target Version:** Minecraft 1.20.1 (**Forge**) and others in the future
- **Java Requirement:** Java 17 - 21
- **Back-porting:** None planned.

> ⚠️ **Developer Prerequisite**
> Pigeon Core is designed to make professional modding *better and simpler, but not necessarily easier*. To use this framework, you must have solid **Java knowledge** and a fundamental understanding of **Minecraft Modding**.

---

## ✨ Key Features

* ⚡ **Auto-Registration System:** A simple yet powerful system that handles registries automatically, drastically reducing boilerplate code.
* 🔄 **Cross-Mod Compatibility:** Built from the ground up to make different mods using this framework natively compatible with one another.
* 🦎 **GeckoLib 4+ Integration:** Built-in, native support for GeckoLib animations. *Note: This is completely optional—the framework works flawlessly even without it.*
* ⚙️ **Fully Customizable:** You retain 100% full control over everything; change what you need.

### 📦 Ecosystem Support

| Category | Supported Features |
| :--- | :--- |
| **Vanilla Extensions** | Entities, Items, Blocks, GUIs, Overlays, and more. |
| **Specialized Systems** | Factions, Vehicles, and Guns (*Timeless and Classics* style). |
| **Third-Party APIs** | Native **GeckoLib 4+** hooks (Optional). |
